# سجل ميزات الخدمات الصحية الحساسة — P4

**الحالة:** `INVENTORY_ONLY`  
**القيمة الإنتاجية:** كل الصفوف `OFF`  
**تنبيه:** هذا سجل حوكمة ومراجعة، وليس تعريفاً برمجياً للميزات ولا يغير إعدادات الإنتاج.

## الهدف

يسجل هذا الملف الأسطح السريرية المقترحة التي **لا يجوز** تفعيلها افتراضياً. يفي السجل بوظيفة التوثيق الأولية لـP4-27 ولا يغلق المعيار؛ الإغلاق يتطلب إثبات المالك والنطاق والطرح والعودة والتدقيق والقيم الإنتاجية بعد مراجعة بشرية [1].

| مفتاح مقترح | السطح المستقبلي | الحالة | النطاق الحالي | شرط الفتح |
|---|---|---|---|---|
| `clinical_read_bridge` | جسر القراءة السريري الموحد | `PROPOSED_NOT_IMPLEMENTED / OFF` | لا نطاق نشط | إغلاق P4-19 إلى P4-25 والموافقة البشرية P4-31 |
| `result_to_plan_read` | عرض النتيجة وخطوة المتابعة | `PROPOSED_NOT_IMPLEMENTED / OFF` | لا نطاق نشط | تفعيل الجسر بعد إثبات مورد النتيجة والتفويض والموافقة والتدقيق |
| `closed_loop_referral` | حالة الإحالة والاستشارة | `PROPOSED_NOT_IMPLEMENTED / OFF` | لا نطاق نشط | نموذج انتقالات خادمي، اختبارات رفض وتزامن، ومراجعة مهنية |

| `citizen_verified_entitlements` | حزمة استحقاقات المواطن بعد تحقق الهوية | `PROPOSED_NOT_IMPLEMENTED / OFF` | لا نطاق نشط | تحقق هوية ساري، تقييم استحقاق خادمي، ومراجعة رفض/انتهاء |
| `ministry_service_constraint_policy` | قيود خدمة وزارية حسب النوع والمدينة والعدد والمدة | `PROPOSED_NOT_IMPLEMENTED / OFF` | لا نطاق نشط | تعيين سياسة موثق، نسخة مدققة، قرار خادمي ذري، وخطة عودة |

## قواعد لا تقبل الاستثناء

لا يُنشأ علم الميزات في عميل Android أو الويب، ولا يقرر العميل قيمته أو نطاقه. يتولى الخادم فقط قراءته وتقييمه وتدقيقه، ويكون الإيقاف هو القيمة الافتراضية. ولا يعتبر وجود اسم في هذا السجل دليلاً على صلاحية أو دور أو حق وصول أو موافقة أو تكامل خارجي.

لا يفتح أي مفتاح بموافقة محادثة أو نجاح CI وحده. لا يفتح إلا بعد استكمال أدلة P4، مراجعة بشرية صريحة، دمج معتمد، تحقق إنتاجي، وتوثيق صاحب العلم والنطاق وخطة العودة.
