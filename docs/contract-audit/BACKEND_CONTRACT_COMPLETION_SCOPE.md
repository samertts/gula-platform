# نطاق مرحلة إكمال العقود الخلفية

## قرار النطاق

تقتصر المرحلة الحالية على **إكمال العقود الخلفية السريرية التي يثبت المستودع تنفيذها الحالي**: الأشعة، ثم الحد الأدنى للطبيب والتمريض. لا تعني هذه المرحلة بناء منصة هوية وطنية أو محرك مخاطر أو وساطة رسائل أو محرك احتفاظ أو تحليلات وطنية كاملة. تحفظ تلك المتطلبات كقرارات معمارية لاحقة ولا تُحوّل إلى سطوح تشغيلية أو وعود جاهزية في هذه المرحلة.

## مبادئ إلزامية للعقود الجديدة

| المبدأ | القرار التنفيذي للمرحلة |
|---|---|
| عقد المجال | تُكتب قواعد المجال في خدمة مستقلة عن HTTP؛ يقتصر الموجه على التحقق والتحويل والاستدعاء. |
| فصل القراءة عن الأمر | تعامل الاستعلامات مع القراءة فقط، وتتعامل الأوامر مع انتقالات الحالة الموثقة لا مع تحديثات عامة. |
| آلة الحالة | لا يعتمد أي انتقال حساس على تعيين حقل حالة مباشر؛ يعرّف كل انتقال مسموح وممنوع واختباره. |
| النطاق والتفويض | يثبت العقد هوية الفاعل والصلاحية وسياق المؤسسة/المنشأة/مساحة العمل قبل الوصول إلى المورد. |
| الذرية والأحداث | إذا احتاج الأمر حدثًا خارجيًا، يُكتب حدث outbox في معاملة الأعمال نفسها أو يؤجل العقد إلى أن تتوافر هذه الآلية. |
| التكرار والتتبع | لا يكرر الأمر الحساس أثره عند الإعادة؛ يسجل مفتاح التكرار ومعرف الترابط حين تدعم البنية ذلك. |
| التدقيق | تسجل العمليات الحساسة فاعلًا وموردًا وقرارًا وسياقًا، ولا تستبدل سجلات التشغيل بسجل تدقيق. |
| عدم الادعاء | لا يوسم العقد «مكتملًا» إلا عند تحقق الخلفية والعقد والتفويض والعزل والتدقيق والاختبارات والتوثيق؛ وما لا ينطبق يوسم بسبب صريح. |

## حدود مؤجلة صراحةً

تظل طبقات الهوية والثقة المتقدمة، مثل MFA ومخاطر الأجهزة وOTP واسترداد الحسابات، وكذلك محرك الاحتفاظ وLegal Hold والإقامة الجغرافية ومراقبة OpenTelemetry والعمال الدائمة، **قرارات معمارية مؤجلة**. لا يجوز تمريرها كمكتملة أو كبديل عن أدلة التنفيذ الفعلية.

## مسارات ذهبية مرشحة

تبدأ الأولوية بمسار الأشعة: `طلب → دراسة → تقرير → مراجعة/تحقق → إصدار`. ولا ينتقل المسار إلى واجهة موحدة قبل ثبوت عقده واختبار العزل. يلي ذلك مسار طبي وتمريضي أدنى يحددهما التدقيق التنفيذي، لا النص التخطيطي وحده.
