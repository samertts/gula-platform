# ابدأ من هنا — GULA LIS

**GULA LIS** هو المنتج الأساسي في مستودع GULA Platform: نظام معلومات مختبري مفتوح المصدر، عربي أولاً، ومصمم لتشغيل المختبرات الطبية مع واجهة ثنائية اللغة ودعم اتجاه الكتابة من اليمين إلى اليسار. يشرح هذا الدليل أقصر طريق لفهم المشروع وتشغيله والمساهمة فيه بأمان.

> **حدود المنتج:** الخلفية الأحادية في `backend/app/` هي مسار الإنتاج المعتمد. المسارات الموجودة في `services/` تمثل تفكيكاً مستقبلياً للخدمات، وليست بديلاً جاهزاً للخلفية الأساسية. تطبيق الويب الرئيسي هو `frontend-v3/`.

## اختر المسار المناسب

| الهدف | المسار | الأمر أو المستند المرجعي |
|---|---|---|
| تشغيل الحزمة المحلية الكاملة | Docker Compose | `cp .env.example .env` ثم `make up` و`make health` |
| تطوير واجهة API | FastAPI | `backend/app/` ثم `cd backend && uvicorn app.main:app --reload --port 8000` |
| تطوير واجهة الويب | React وTypeScript | `cd frontend-v3 && npm ci && npm run dev` |
| تشغيل اختبارات الخلفية | Pytest | `cd backend && python -m pytest tests/ -v` |
| تشغيل اختبارات الواجهة | Vitest | `cd frontend-v3 && npm test` |
| فهم النشر والإنتاج | Docker وKubernetes وHelm | [دليل النشر](../PRODUCTION_DEPLOYMENT.md) و[دليل البنية](../ARCHITECTURE.md) |

## خريطة المستودع

| المجلد | الغرض |
|---|---|
| `backend/app/` | تطبيق FastAPI الأساسي، ونماذج المجال، وطبقات الأمن، ومسارات API. |
| `frontend-v3/` | عميل الويب الأساسي المبني بـ React وTypeScript. |
| `shared/` | عقود ومكوّنات مشتركة بين الخدمات والعملاء. |
| `mobile/` | عملاء Android وiOS وسطح المكتب. |
| `helm/` و`k8s/` و`terraform/` | تعريفات النشر والبنية التحتية. |
| `docs/` | مواصفات المنتج وقرارات المعمارية وأدلة التشغيل. |
| `services/` | تجارب تفكيك الخدمات المستقبلية، وليست مسار التشغيل الافتراضي. |

## قواعد أمان وتشغيل أساسية

لا تحفظ أسراراً حقيقية في Git. استخدم `.env.example` كنقطة بداية، وأنشئ قيماً عشوائية قوية قبل النشر. يرفض تطبيق الإنتاج بدء التشغيل إذا لم تتوفر أسرار الحرجة أو إذا كان `BASE_URL` غير HTTPS. لا تفعّل وضع العرض إلا مع قاعدة بيانات وRedis منفصلين صراحةً؛ فالوضع مصمم للتدريب فقط ولا يجوز ربطه ببيانات سريرية حقيقية.

عند تغيير واجهة API أو عقود البيانات، ابدأ من `backend/app/`، وأضف اختبار انحدار، ثم حدّث العميل الأساسي في `frontend-v3/` والوثائق ذات الصلة. لا تعتمد على إخفاء عنصر في الواجهة كوسيلة تفويض: جميع العمليات الحساسة يجب أن تُفرض في الخادم عبر الدور والصلاحيات والسياق التنظيمي.

## قبل فتح طلب دمج

نفّذ اختبارات الجزء الذي غيّرته أولاً، ثم راجع [دليل المساهمة](../CONTRIBUTING.md) وقواعد [الأمان](../SECURITY.md). يجب أن تكون التغييرات صغيرة وقابلة للمراجعة، وألا تتضمن أسراراً أو بيانات مرضى أو ملفات مبنية. يوفر ملف `Makefile` أوامر مركزية للصحة والاختبار والفحص التشغيلي.
