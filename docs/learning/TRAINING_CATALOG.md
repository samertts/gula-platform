# GULA Training Catalog

## Overview

This comprehensive training catalog defines all learning modules available on the
GULA Learning Platform. Modules are organized into seven tracks, each targeting
specific roles and competencies. Every module is mapped to the GULA Competency
Framework and supports both Arabic and English delivery.

### Module ID Convention

| Prefix | Track |
|--------|-------|
| `CL-` | Clinical Laboratory Track |
| `CT-` | Clinical Track |
| `SC-` | Security & Compliance Track |
| `AD-` | Administrator Track |
| `DV-` | Developer Track |
| `IN-` | Infrastructure Track |
| `NP-` | National Platform Track |
