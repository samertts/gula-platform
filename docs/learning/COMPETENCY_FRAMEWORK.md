# GULA Competency Framework

## Overview

The GULA Competency Framework defines the knowledge, skills, and abilities required
for effective use of the GULA healthcare platform across all roles and disciplines.
It serves as the foundation for learning path generation, certification requirements,
and ongoing professional development.

### Framework Principles

1. **Role-Aligned**: Competencies are defined per role with specific requirements
2. **Progressive**: Levels build on each other from novice to expert
3. **Measurable**: Each competency has clear assessment criteria
4. **Arabic-First**: Arabic medical terminology and workflows are core competencies
5. **Regulatory-Integrated**: Iraqi MoH, ISO, and international standards are embedded
6. **Dynamic**: Framework evolves with platform capabilities and regulations

## 2. Proficiency Levels

### Level 1: Novice

| Attribute | Description |
|-----------|-------------|
| **Definition** | Minimal or theoretical knowledge only; requires supervision |
| **Behavior** | Follows step-by-step instructions; unable to adapt to variations |
| **Supervision** | Requires direct, immediate supervision |
| **Assessment** | Can answer basic knowledge questions |
| **Example** | New lab technician who completed orientation but hasn't worked independently |

### Level 2: Advanced Beginner

| Attribute | Description |
|-----------|-------------|
| **Definition** | Working knowledge with limited independent practice |
| **Behavior** | Can perform routine tasks independently; needs guidance for edge cases |
| **Supervision** | Requires occasional supervision |
| **Assessment** | Can perform routine tasks in standard scenarios |
| **Example** | Lab technician with 3 months of GULA experience handling routine orders |

### Level 3: Competent

| Attribute | Description |
|-----------|-------------|
| **Definition** | Full independent capability for standard situations |
| **Behavior** | Handles most situations independently; recognizes own limitations |
| **Supervision** | Independent for routine work; seeks guidance for complex cases |
| **Assessment** | Can handle all standard workflows without assistance |
| **Example** | Experienced lab scientist managing daily operations with minimal oversight |

### Level 4: Proficient

| Attribute | Description |
|-----------|-------------|
| **Definition** | Deep understanding; handles complex situations |
| **Behavior** | Sees the big picture; anticipates problems; mentors others |
| **Supervision** | Independent; serves as resource for others |
| **Assessment** | Can handle complex cases and teach others |
| **Example** | Senior lab scientist who trains new staff and optimizes workflows |

### Level 5: Expert

| Attribute | Description |
|-----------|-------------|
| **Definition** | Definitive source of knowledge; innovates and leads |
| **Behavior** | Develops best practices; creates new solutions; leads improvement |
| **Supervision** | Provides supervision and guidance to entire team |
| **Assessment** | Can develop new procedures and lead organizational change |
| **Example** | Lab manager/supervisor who designs QC programs and leads accreditation |

### Level Progression Criteria

| Level | Experience | Training Hours | Assessments Passed | Practical Demonstrations |
|-------|------------|----------------|-------------------|--------------------------|
| Novice | N/A | 0-10 | 0 | 0 |
| Advanced Beginner | 3-6 months | 10-40 | 2+ | 1+ |
| Competent | 6-18 months | 40-100 | 5+ | 3+ |
| Proficient | 18-36 months | 100-200 | 10+ | 5+ |
| Expert | 36+ months | 200+ | 15+ | 10+ |

## 4. Assessment Methods

| Method | Description | Best For | Reliability | Effort |
|--------|-------------|----------|-------------|--------|
| **Multiple Choice** | Standard knowledge quiz | Knowledge recall, terminology | Medium | Low |
| **Practical Exam** | Hands-on task in sandbox environment | Platform operations, workflows | High | Medium |
| **Case Study** | Real-world scenario analysis | Clinical reasoning, problem-solving | High | Medium |
| **Peer Review** | Colleague observation and evaluation | Soft skills, teamwork | Medium | Low |
| **Supervisor Assessment** | Manager observation over time | Leadership, overall competency | High | High |
| **Simulation** | Virtual scenario completion | Emergency response, complex workflows | High | High |
| **Portfolio** | Collection of work evidence | Comprehensive competency proof | High | High |
| **Oral Examination** | Structured interview | Deep knowledge, rationale | High | High |
| **Self-Assessment** | User rates own competency | Awareness, gap identification | Low | Low |
| **Platform Analytics** | Automated usage pattern analysis | Practical proficiency, efficiency | High | None |

### Assessment Blueprint

Each competency assessment should include:

1. **Objective**: Clear statement of what is being assessed
2. **Method**: One or more assessment methods
3. **Criteria**: Specific, measurable success criteria
4. **Scoring Rubric**: How performance is scored
5. **Pass Threshold**: Minimum score for competency attainment
6. **Verification**: How assessment integrity is ensured

## 7. Competency Maintenance

### Ongoing Requirements

| Pro Level | Assessment Interval | CME Hours/Year | Practical Renewal |
|-----------|-------------------|----------------|-------------------|
| Novice | 3 months | N/A | N/A |
| Advanced Beginner | 6 months | 10-20 | 1 demonstration |
| Competent | 12 months | 20-35 | 1 case study |
| Proficient | 18 months | 30-50 | 1 portfolio submission |
| Expert | 24 months | 40-60 | 1 peer review + portfolio |

### CME/CPD Categories

| Category | Description | Max % of Total |
|----------|-------------|----------------|
| **Category 1** | Formal GULA learning modules | 60% |
| **Category 1A** | Attending GULA conferences/webinars | 20% |
| **Category 2** | External CME (prior approved) | 30% |
| **Category 3** | Teaching and mentoring | 15% |
| **Category 4** | Research and publication | 15% |
| **Category 5** | Self-directed learning | 10% |

### Competency Decay

If a user does not maintain CME requirements or fails reassessment:

1. **Grace Period**: 90 days after expiry
2. **Notification**: Reminders at 90, 60, 30, and 7 days before expiry
3. **Suspension**: Certificate suspended until CME gap filled
4. **Reactivation**: Complete CME gap + refresher assessment
5. **Revocation**: After 1 year of inactivity, full recertification required

### Competency Review Cycle

The framework itself is reviewed annually:

```
Q1: Data collection (assessment results, feedback)
Q2: Analysis (gap identification, market changes)
Q3: Framework update (role changes, new competencies)
Q4: Publication and rollout
```
