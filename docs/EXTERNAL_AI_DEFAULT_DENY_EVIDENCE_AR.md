# دليل default-deny لمزودي الذكاء الخارجي

**الفرع:** `fix/external-ai-default-deny`
**القاعدة:** `release/clinical-safety-2026q3-rc1` عند `dfd93962`
**التزام التنفيذ:** `abfca1d7`

## الخطر المعالج

مسار `/api/ai/interpret/{token}` يبني prompt من نتائج مختبر وسياق عمري/نوع اجتماعي ثم يمرره إلى سلسلة مزودين. قبل هذه الدفعة، كان وجود مفتاح Gemini أو Groq كافياً لإضافتهما إلى fallback بعد Ollama المحلي، بما في ذلك عند تعذر المحلي. كذلك كان chat يستدعي Gemini مباشرة ثم يعود إلى السلسلة.

## الضابط

أضيف `ALLOW_EXTERNAL_AI` بوصفه تمكيناً صريحاً وحساساً لحماية الخصوصية. قيمته الافتراضية هي الرفض. عند غيابه أو أي قيمة غير `true`:

| المسار | السلوك |
|---|---|
| Google gateway | `is_configured()` يرجع false حتى لو وُجد مفتاح، وتُرفض generate قبل HTTP أو SDK. |
| Groq | يرفض قبل إنشاء عميل HTTP. |
| fallback السريري | لا يضيف Gemini أو Groq؛ يستخدم Ollama المحلي فقط إن ضُبط. |
| chat | استدعاء Gemini يرفض ثم يستخدم المسار المحلي فقط أو رسالة عدم توفر. |

لم يُكشف أو يُنشأ أو يُعدل أي secret. لا يغير الحارس نتائج سريرية أو يقدم تشخيصاً أو يسمح بحالة سريرية متحولة.

## متطلبات قبل أي تمكين مستقبلي

لا تُضبط `ALLOW_EXTERNAL_AI=true` إلا بعد اعتماد privacy/legal مكتوب، اتفاقية معالجة بيانات/موقع معالجة مقبولة، data-minimization وde-identification مراجعان، سياسة consent أو أساس قانوني ملائم، إدارة مفتاح في secret manager، allow-list/egress controls، مراقبة وتدقيق، واختبارات UAT تركيبية. هذه الشروط ليست متحققة بهذه الدفعة؛ لذلك يبقى التفعيل السحابي وGO بحالة NO-GO.
