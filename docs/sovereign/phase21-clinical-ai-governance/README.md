# Phase 21 — National Clinical AI Governance

**Goal:** Constrain AI operational authority, preserve clinical
accountability, ensure explainability and auditability, and guarantee
medico-legal defensibility.

This phase sits **on top of** Phase 18 §AI governance constraints.
Phase 18 says **what is allowed**; Phase 21 says **how we enforce it**.
