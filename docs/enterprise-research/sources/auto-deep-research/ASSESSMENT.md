GULA requirements that must be stronger

The external project must NOT be treated as the final GULA architecture.

GULA Research Engine must additionally provide:

1. Source provenance
2. Claim-to-evidence mapping
3. Independent verification
4. Contradiction detection
5. Source authority ranking
6. Publication-date awareness
7. Iraqi official-source prioritization
8. Arabic/English source handling
9. Human review
10. Immutable audit trail
11. Reproducible research runs
12. Research versioning
13. Evidence preservation
14. Citation validation
15. Security boundaries
16. Prompt/tool isolation

Explicit exclusions

Do NOT import:

- UI
- unrelated application code
- unrelated dependencies
- deployment stack
- credentials
- API keys
- example secrets
- project-specific business logic
