# دليل ربط المستشفيات الجديد - منصة GULA الصحية الوطنية
**الإصدار:** 1.0
**تاريخ التحديث:** 12 أغسطس 2026

يعتمد نظام GULA على هيكلية **Multi-Tenancy** صارمة لضمان عزل البيانات الطبية لكل مؤسسة. يوضح هذا الدليل الخطوات التقنية لتعريف مستشفى جديد وتفعيله عبر البوابة الموحدة.

---

## 1. الخطوة الأولى: تعريف المؤسسة (Tenant Registration)
يجب تسجيل المستشفى في قاعدة البيانات المركزية للحصول على معرف فريد (`hospital_id`). يتم ذلك عبر طلب API مؤمن بصلاحيات "مدير النظام":

### نموذج طلب التسجيل (API Request):
```http
POST /api/v1/admin/tenants/register
Content-Type: application/json
Authorization: Bearer <ADMIN_TOKEN>

{
  "name": "مستشفى بغداد التعليمي",
  "type": "HOSPITAL",
  "license_number": "IQ-H-2026-001",
  "contact_email": "admin@baghdad-hosp.gov.iq",
  "subdomain": "baghdad-hosp"
}
```

---

## 2. الخطوة الثانية: إعدادات الأمان وعزل البيانات
بمجرد التسجيل، يقوم النظام تلقائياً بإنشاء:
- **معرف المؤسسة (UUID):** يستخدم في كافة العمليات السريرية.
- **مفاتيح التشفير:** لتأمين صور الأشعة (DICOM) الخاصة بالمستشفى.
- **قواعد الـ RLS:** لضمان عدم وصول أطباء المستشفيات الأخرى لبيانات هذا المستشفى.

---

## 3. الخطوة الثالثة: تفعيل الوصول عبر البوابة الموحدة
لتمكين الموظفين من الدخول، يجب ربط النطاق الفرعي للمستشفى بالبوابة الموحدة.

| المكون | الإجراء التقني |
| :--- | :--- |
| **DNS** | إضافة سجل CNAME يشير من `baghdad-hosp.gula-platform.org` إلى `www.gula-platform.org`. |
| **Auth** | تعريف موصل OAuth خاص بالمستشفى في لوحة التحكم (Connector Config). |
| **Portal** | إضافة أيقونة المستشفى في واجهة البوابة الموحدة للمستخدمين المصرح لهم. |

---

## 4. الخطوة الرابعة: تهيئة الأقسام الطبية
يتم تفعيل الوحدات المطلوبة للمستشفى الجديد عبر واجهة الإدارة:
1. **تطبيق الطبيب:** ربط العيادات الخارجية.
2. **المختبر:** تعريف أجهزة التحليل وتكاملها مع `GULA Laboratory`.
3. **الأشعة:** إعداد خادم PACS الخاص بالمستشفى للربط مع `AI Fabric`.

---

## 5. التحقق النهائي (Verification)
بعد إتمام الربط، يمكن للمدير التقني للمستشفى إرسال أمر `/status` لبوت تليغرام للتأكد من جاهزية الاتصال:
> 💬 `/status baghdad-hosp`
> 🟢 **النتيجة:** النظام نشط، قاعدة البيانات متصلة، عزل البيانات مفعل.

---
*جميع العمليات تخضع لرقابة وزارة الصحة العراقية ومعايير الأمن السيبراني الوطنية.*
