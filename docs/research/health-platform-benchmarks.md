# معايير مرجعية لتحسين GULA Health Platform

**تاريخ الجمع:** 13 أغسطس 2026
**الغرض:** تحويل الممارسات الدولية في المنصات الصحية إلى متطلبات هندسية ومنتجية قابلة للتنفيذ داخل GULA.

## الاستنتاجات الموثقة

| المحور | الدليل المرجعي | الدلالة التنفيذية لمنصة GULA |
| --- | --- | --- |
| التشغيل البيني | تعرّف منظمة الصحة العالمية إرشادات SMART بأنها **معيارية، قابلة للقراءة الآلية، تكيفية، قائمة على المتطلبات وقابلة للاختبار**، وتربطها بمكوّنات قابلة لإعادة الاستخدام مثل معايير التشغيل البيني والمكتبات والخوارزميات والمواصفات. [1] | اعتماد عقود FHIR أولاً، وملفات تعريف محلية قابلة للإصدار، واختبارات توافق آلية بدل ربط الشركاء بنماذج قاعدة البيانات الداخلية. |
| سلامة البيانات السريرية | تذكر منظمة الصحة العالمية أن FHIR وICD وCQL عناصر مفتوحة ناشئة لضمان تبادل البيانات المتمحور حول الشخص، وتوحيد المصطلحات، وحساب دعم القرار والمؤشرات. [2] | بناء طبقة terminology وprovenance وقواعد قرار سريرية قابلة للمراجعة؛ لا يُعامل الذكاء الاصطناعي كمصدر قرار سريري مستقل. |
| الرعاية غير المتصلة | تشرح منظمة الصحة العالمية أن تطبيقات الميدان محدودة الموارد تحتاج تخزيناً محلياً وبحثاً ومزامنة وواجهات معيارية، وأن Android FHIR SDK يوفّر هذه المكوّنات. [2] | تطوير أسلوب offline-first لتطبيقات GULA، مع طوابير مزامنة آمنة، كشف التعارضات، ومقاييس تأخر المزامنة. |
| النظام الصحي المتصل | تصف ONC FHIR بأنه معيار واسع الاستخدام قائم على API لتمثيل المعلومات الصحية وتبادلها، بما يقوّي التشغيل البيني والتطبيقات الجديدة والنتائج الصحية. [3] | إنشاء FHIR Gateway مقيد بالنطاق والصلاحيات، وتوفير Sandbox ومجموعات توافق للشركاء والمختبرات والصيدليات ومقدمي الخدمة. |
| رحلة الرعاية الكاملة | تعرض منصة معايير التشغيل البيني حالات استخدام تشمل المختبرات، الصور، الأدوية، الإحالات، الخطة العلاجية، موافقة المريض، النتائج التي يبلّغ عنها المريض، وجودة الرعاية. [4] | ترتيب خارطة المنتج حول رحلة المريض والنتيجة السريرية، لا حول الشاشات المنفصلة: هوية موثوقة، إحالة/طلب، عينة/نتيجة، متابعة، موافقة ومشاركة، قياس جودة سكاني. |
