# مراجع خارجية لتوافق CI لسطح المكتب

- أرشيف Flutter الرسمي: <https://docs.flutter.dev/install/archive>. استُخدم للتحقق من توفر إصدارات مستقرة حديثة تدعم سلسلة Dart الأحدث المطلوبة لاعتماديات تطبيق سطح المكتب.
- صفحة إصدارات Flutter الرسمية: <https://docs.flutter.dev/release/release-notes>.
- صفحة حزمة `file_picker` وإصداراتها: <https://pub.dev/packages/file_picker/versions>. بينت أن `8.3.7` هو آخر إصدار منشور ضمن السلسلة 8، وأن `8.3.8` غير منشور.
- صفحة حزمة `esc_pos_utils_plus`: <https://pub.dev/packages/esc_pos_utils_plus>. استُخدمت لتقييم مسارات تحديث طبقة ESC/POS عند ظهور تعارض `image`.
- صفحة حزمة `printing` وإصداراتها: <https://pub.dev/packages/printing/versions>. استُخدمت لتشخيص توافق إصدارات `image` وDart.

هذه المراجع معلومات تشخيصية فقط؛ قرارات الدمج النهائية تستند إلى تشغيلات GitHub Actions الفعلية للمستودع.
