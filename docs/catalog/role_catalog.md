## Findings

- Same concept, 4 different names: top admin = super_admin / master_admin / system_admin; lab lead = lab_admin / lab_manager / LAB_ADMIN; technician = lab_tech / technician / lab_technician; ministry = ministry / ministry_admin / ministry_official.
- Duplicate role pairs in System B: ministry_admin≡province_admin, admin≡lab_admin, staff≡lab_staff.
- require_role('national_admin','directorate_admin') references roles absent from EXTENDED_ROLE_LEVELS (level 0).
- LabUser.role is a free-form string (default 'staff'), not constrained to any vocabulary.
- Role DB table (92 seeded perms) coexists with in-memory map (16) — effective permissions differ by auth path.
