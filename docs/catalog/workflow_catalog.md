## Order creation with results — complete

- **Trigger:** POST /orders or POST /batch/orders
- **Steps:** idempotency check (Redis 24h) → patient scoped to lab → doctor validation → LabOrder(status=completed) → LabResult per test with flag → public token + hash per result → audit log_action → sharing links → critical alert → events order.created/result.critical
- **Entities:** LabOrder, LabResult, Patient, LabUser, AuditLog
- **APIs:** POST /orders, GET /orders, GET /orders/{id}, POST /batch/orders
