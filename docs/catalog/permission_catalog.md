## Findings

- Two inverted formats: System A read:patients vs Systems B–D patients:read — a cross-system has_permission with the wrong string silently fails.
- 3 orphan permission strings lock out 15 routes permanently (knowledge_graph, simulation).
- citizen has ZERO extended permissions; citizen portal uses inline role checks.
- authorization_service._check_assignment_permission is a stub returning True.
- Effective permissions differ by auth path: JWT require_permission checks only the 16-string map; DB-assigned users get bootstrap 92 ∩ role_permissions.
