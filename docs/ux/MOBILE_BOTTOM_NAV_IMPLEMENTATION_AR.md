# تنفيذ تحسينات Mobile Bottom Nav في GULA

## النطاق

تنفذ هذه الدفعة تحسينات آمنة على شريط التنقل السفلي للهاتف دون إضافة مسارات أو صلاحيات أو عمليات سريرية. يبقى الشريط طبقة تنقل مرئية فقط، وتبقى المصادقة والتفويض النهائيان خادميين.

## التغييرات المنفذة

| المجال | التنفيذ |
|---|---|
| المصدر canonical | تُستخرج المسارات والصلاحيات من `NAV_ITEMS` بدل تكرار تعريف الصلاحيات داخل الشريط |
| i18n | نُقلت التسميات وaria labels إلى موارد العربية والإنجليزية والكردية والتركمانية والآشورية |
| live mode | لا تظهر الروابط المقيدة قبل وجود `effectivePermissions` منعكسة من الخادم |
| demo mode | يستخدم الترشيح الحالي القائم على الدور التجريبي دون إنشاء صلاحيات جديدة |
| الحالة النشطة | أضيف route boundary مع إزالة trailing slash، و`aria-current="page"`، ومؤشر بصري علوي |
| الوصول | أضيف `aria-label` يعلن الصفحة الحالية و`aria-expanded` لزر المزيد |
| الحركة | أضيفت انتقالات آمنة وحالة ضغط خفيفة مع احترام `prefers-reduced-motion` |
| الاتجاه | يعتمد النص على i18n، ويستمر اتجاه التطبيق من `LocaleContext` |
| المساحات الآمنة | حُفظ دعم `env(safe-area-inset-bottom)` مع padding سفلي مناسب للحواف الآمنة |
| زر المزيد | يستخدم Button المشترك مع تمرير `isMenuOpen`؛ فتح Sidebar الحالي لم يتغير |

## تدقيق i18n واللغات المحلية

أُجري تدقيق مباشر لموارد الشريط وتجربة زر «المزيد». أصبحت المفاتيح التالية متاحة بدل النصوص الثابتة: اسم التنقل، فتح الأقسام، المزيد، الصفحة الحالية، تخطي المحتوى، تغيير اللغة، إغلاق الأقسام، توسيع/طي القائمة، مركز العمليات، المستخدم الافتراضي، القراءة فقط، ورسالة الجلسة الاصطناعية. كما أضيفت أسماء مجموعات Sidebar العشر إلى نفس مساحة `mobileNav.groups`.

| اللغة | المورد | الاتجاه | حالة Mobile Bottom Nav وMore |
|---|---|---|---|
| العربية | `ar` | RTL | مكتمل ومختبر |
| الإنجليزية | `en` | LTR | مكتمل ومختبر |
| الكردية السورانية | `ku` | RTL | مكتمل ومختبر |
| التركمانية | `tk` | LTR | مكتمل ومختبر |
| الآشورية | `syr` | RTL | مكتمل ومختبر |
| العربية العراقية | `ar-IQ` | RTL | يستخدم مورد العربية الحالي بصورة صريحة |
| الفارسية | `fa` | RTL | أضيف مورد `fa` محدود للشريط وSidebar؛ بقية الواجهة تستمر عبر fallback الإنجليزية إلى أن يكتمل مورد فارسي شامل |

يُحسب اتجاه الجذر من `getLocaleDirection` عبر `LocaleContext`، ولم يعد `DashboardLayout` يختزل الاتجاه إلى اختبار `locale === "ar"`. كما أصبح زر تغيير اللغة يدور عبر `localeOptions` بدل التبديل الثنائي بين العربية والإنجليزية. وتُستخدم مفاتيح i18n أيضًا في Sidebar الذي يفتحه زر «المزيد»، بما يشمل عنوان القائمة، مجموعات التنقل، النص الافتراضي للمستخدم، حالة القراءة فقط، ورسالة إغلاق القائمة.

أضيف الاختبار `src/i18n/mobileNavResources.test.ts` للتحقق من وجود كل مفاتيح التنقل والوصول ومجموعات Sidebar في الموارد المحلية الخمسة، والتحقق من اتجاه RTL/LTR المعلن. هذا الاختبار لا يعتبر صحة الصياغة اللغوية بديلًا عن مراجعة بشرية من متحدث أصلي؛ بل يثبت اكتمال المفاتيح وعدم سقوطها إلى key names أو نص فارغ.

## الحدود المتعمدة

لم تُضف أرقام تنبيهات أو polling أو بيانات سريرية. لم يُنفذ Drawer جديد أو focus trap جديد؛ زر المزيد يستمر في فتح Sidebar الحالي، وتبقى مراجعة دمج سلوك التركيز في Drawer ضمن دفعة لاحقة. لم يُنفذ أي إجراء كتابة من الشريط، ولا توجد صلاحية تُستنتج من إظهار عنصر بصري.

## الاختبارات

نجحت اختبارات MobileBottomNav واختبار موارد i18n الجديد: **16 ملف اختبارًا و54 اختبارًا ناجحًا**. تغطي النتائج الترجمة، حالة المسار المتداخل، `aria-expanded`، منع الروابط المقيدة في live mode عند غياب الصلاحيات المنعكسة، اكتمال مفاتيح اللغات المحلية، واتجاهات RTL/LTR. كما نجحت اختبارات frontend العامة وlint وtypecheck وbuild وPWA وحواجز governance وcontract وintegration boundary وdata-source وaudit artifacts وbundle budget. آخر قياس محلي للحزمة: **1428.8 KiB** إجمالًا، وentry JS بحجم **338.0 KiB**، وCSS بحجم **134.4 KiB**، دون مخالفات للميزانية.
