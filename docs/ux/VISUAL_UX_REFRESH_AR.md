# تحديث التصميم المرئي وتجربة المستخدم في GULA

## نطاق الدفعة

تطبق هذه الدفعة تحسينًا بصريًا مشتركًا على واجهات GULA اعتمادًا على اتجاه Stitch الحالي، مع إبقاء منطق المصادقة والتفويض والمسارات والبيانات كما هو. الهدف هو جعل الواجهة أكثر هدوءًا ووضوحًا واستجابة في العربية واللغات المدعومة، من دون فتح أي عملية سريرية أو تغيير server-authoritative authorization.

## القرارات البصرية

| المجال | القرار |
|---|---|
| الهوية | تثبيت العلامة المشتركة GULA/جولا مع تدرج teal–navy، مساحة تنفس أكبر، وأيقونة زخرفية غير مسموعة لقارئات الشاشة |
| الألوان | الحفاظ على لوحة Stitch الحالية وإضافة `primary-strong` وظلال منخفضة الكثافة للتمييز بين السطح والمحتوى |
| الأسطح | استخدام white/neutral surfaces مع حدود خفيفة وظلال ناعمة بدل الحدود الثقيلة أو التباين الحاد |
| RTL | إبقاء اتجاه التطبيق تابعًا للغة، وتحسين skip-link والـcontrols المشتركة دون افتراض أن العربية هي اللغة الوحيدة |
| المظهر | استبدال رموز النص غير الدلالية لأداة المظهر بأيقونات Sun/Moon/Monitor مع labels وtitles واضحة |
| الحركة | إضافة انتقالات قصيرة ومحدودة، مع `prefers-reduced-motion` شامل وإلغاء الحركة عند طلب المستخدم |
| التركيز | توحيد focus ring مرئي بلون teal مع offset واضح للوحة المفاتيح |
| الحالات | جعل loading في Button يعلن `aria-busy` ويعطل الزر دون إزالة محتواه أو تغيير مسار العملية |
| الهاتف | تقليل padding الافتراضي للبطاقات على الشاشات الصغيرة مع إبقاء المساحات الواسعة على desktop |

## الأسطح التي شملها التحديث

أثر التحديث على `index.css`، ومكوّنات `Button` و`Card`، وهوية `GulaBrand` و`DemoEnvironmentBadge`، إضافة إلى `AuthLayout` و`DashboardLayout`. هذه نقاط مشتركة عالية الأثر، ولذلك لم تُضف شاشة جديدة ولم تُعدل عقود API أو workspace switching أو feature flags.

## حدود السلامة

لا تحتوي الدفعة على عمليات Check-in أو Triage أو Orders أو Results أو Close، ولا تغيّر صلاحيات أو عضويات أو مساحة عمل أو بيانات سريرية. الـdemo badge ما يزال يوضح أن البيئة اصطناعية وقراءة فقط. النجاح البصري أو نجاح build لا يُعد موافقة بشرية أو تصريح نشر.

## التحقق

| الفحص | النتيجة |
|---|---|
| `npm run build` داخل `frontend-v3` | ناجح؛ تم توليد Vite/PWA build |
| `npm run test` داخل `frontend-v3` | ناجح؛ 14 ملف اختبار و49 اختبارًا |
| `npm run lint` داخل `frontend-v3` | ناجح دون تحذيرات |
| اختبار Button الجديد | يثبت `aria-busy` والتعطيل أثناء loading |
| typecheck الشامل | توجد ديون سابقة واسعة في الفرع الأساسي؛ لم تظهر أخطاء مرتبطة بالملفات المعدلة في الفحص التشخيصي |

## المراجعة التالية

يجب مراجعة التغيير بصريًا في Preview على أحجام الهاتف وdesktop، وباللغات العربية والإنجليزية، مع اختبار لوحة المفاتيح وdark/system theme. لا يُدمج PR ولا يُنشر تلقائيًا دون مراجعة بشرية صريحة.
