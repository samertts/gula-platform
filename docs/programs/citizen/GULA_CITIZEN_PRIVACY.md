# GULA Citizen Privacy

Privacy Center يعرض account data، health-data categories، consents، sharing permissions، connected services، access history، وإعدادات الخصوصية. يتيح view/revoke/manage وطلبات التصحيح أو الوصول حيث تسمح القاعدة والمنظومة، دون ادعاء قانوني غير موثق.

Access history تعرض actor وorganization ووقت الوصول ونوع المورد والغرض وbreak-glass indication عند توفره، ولا تعرض internal security details أو PHI إضافياً يرفع المخاطر. كل access/download/share يمر عبر authorization وaudit.

الموقع القانوني Privacy Policy وTerms يجب أن يكونا صفحات حقيقية versioned وقابلتين للوصول المباشر وإعادة التحميل، مع consent غير محدد مسبقاً وروابط keyboard-accessible. لا يوضع national ID أو tokens أو health data في client logs/analytics.
