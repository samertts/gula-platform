# Citizen Workspace

Citizen Workspace هو سطح المواطن داخل `frontend-v3` canonical web، ويستخدم GULA shell المشترك للهوية والتنقل والإشعارات والمساعدة والإعدادات والأمان. أضيف مسار `/citizen` منفصل عن `/citizen-platform` الإداري للحفاظ على التوافق وعدم تحويل صفحة الإدارة إلى واجهة مواطن.

يعرض workspace السياق الحالي، حالة التحقق، حالة المزامنة، آخر تحديث، ومصدر كل معلومة. لا يختار المستخدم citizen ID أو patient ID من الواجهة. own-context endpoints تستخرج المواطن من العلاقة النشطة في الخادم.

التصميم progressive disclosure: تبدأ الصفحة بملخص آمن، ثم تنتقل إلى الملف الصحي، المواعيد، النتائج المنشورة، الأدوية، التنبيهات، المستندات، الخصوصية، والمساعدة. كل module لا يظهر أو لا يعمل قبل توفر عقد API وتفويض واختبارات مناسبة.
