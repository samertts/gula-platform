# GULA Platform — Engineering Assessment

**Version:** 2.1.0
**Date:** 2026-07-08
**Classification:** Internal — Engineering

---

## Purpose

This directory contains the complete Engineering Assessment of the GULA Platform. Every component — backend, frontend, database, security, testing, deployment — is analysed for production readiness, technical debt, and compliance with the Engineering Constitution (`CLAUDE.md`).

## Structure

| Directory | Scope |
|-----------|-------|
| `architecture/` | System architecture, module boundaries, dependency graphs |
| `backend/` | FastAPI monolith, routes, models, services, integration |
| `frontend/` | Frontend-v2 (React/Firebase), client (tRPC), legacy frontend |
| `security/` | Auth, RBAC, encryption, audit, rate limiting, firewall |
| `database/` | PostgreSQL schema, migrations, query performance, Redis |
| `testing/` | Test coverage, quality gates, integration test health |
| `performance/` | Load testing, stress testing, profiling, optimisation |
| `compliance/` | Regulatory compliance, government readiness, data governance |
| `deployment/` | Docker Compose, Kubernetes, DigitalOcean, CI/CD |
| `documentation/` | Documentation audit, coverage gaps, quality |
| `reports/` | Generated assessment reports, summaries, dashboards |
| `scripts/` | Automation scripts for assessment generation and validation |

## Reports

Reports are auto-generated by scripts in `assessment/scripts/`. See `assessment/scripts/README.md` for usage.
