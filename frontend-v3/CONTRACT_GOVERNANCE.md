# حوكمة العقود داخل `frontend-v3`

يستدعي الأمر `pnpm verify:contracts` ضابطًا خادميًا-محليًا يمنع انجراف واجهة الإصدار الثالث عن **مصدر الحقيقة** المحفوظ في `apps/gula-platform-ui-refresh`.

يتحقق الضابط من وجود عقدي `patients.read` و`orders.read` وصلاحيتيهما وسياق المنشأة المطلوب في السجل المرجعي، ثم يفحص بوابة `workspaceScopedReads` للتأكد من أنها تتحقق من `GET /authz/me` ومن قرار `POST /authz/check` مع `lab_id` قبل أي قراءة نطاقية. كما يطلب أن تعلن صفحتا المرضى والطلبات معرف العقد والصلاحية وسياق المنشأة صراحة.

> لا يجعل الضابط الواجهة مخولة بذاتها. يبقى القرار النهائي في الخلفية، وتبقى الصفحة في حالة منع آمنة عند غياب الجلسة أو ربط المنشأة أو موافقة الصلاحية.

| الأمر | الغرض |
| --- | --- |
| `pnpm typecheck` | فحص الأنواع |
| `pnpm test` | اختبارات بوابة القراءة وجسر المسارات |
| `pnpm verify:unification` | تحقق سجل أسطح الواجهة وجسر التوافق |
| `pnpm verify:contracts` | تحقق سجل العقود والصلاحيات وسياق المنشأة |
| `pnpm check` | تشغيل الحراس السابقة ثم البناء |
