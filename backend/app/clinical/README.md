# Clinical Domain

تحتوي هذه الحزمة على **ضوابط الأوامر السريرية المشتركة** وقواعد الحالة التي تستعملها مسارات ذات أثر سريري. وهي ليست endpoint عاماً ولا مساراً مستقلاً لإنشاء نتيجة أو اعتمادها أو إطلاقها.

## المسؤوليات

| المكوّن | المسؤولية |
|---|---|
| `command_guard.py` | تنفيذ متطلبات الأمر الحرج: النسخة المتفائلة و`If-Match` ومفتاح عدم التكرار والتدقيق ضمن معاملة واحدة. |
| `enums.py` و`models.py` | أنواع وحالات وبيانات داخلية مشتركة للسياق السريري. |
| `observability.py` | قياسات وملاحظات قابلة للرصد لا يجب أن تحتوي PHI أو أسراراً. |

## القيود غير القابلة للتجاوز

كل كتابة سريرية حرجة يجب أن تمر بحارس الأمر المناسب وتفويض الدور والعزل المؤسسي وسجل تدقيق. لا تضف هنا انتقال حالة جديداً أو مسار bypass للنتيجة أو العينة أو الأمر. يجب أن يكون أي انتقال محدوداً بآلة حالات صريحة، ويرفض التعارض وإعادة الإرسال غير المتوافقة بشكل مغلق.

## الاعتمادات والاختبار

تستدعي routes/services الحارس؛ ولا يجوز أن تعتمد هذه الحزمة على HTTP route لتحقيق قواعدها. عند تعديلها، شغّل اختبارات الحارس والأوامر السريرية والانحدار الخلفي المعلن من مجلد `backend/`.

> هذه الوثيقة تشرح البنية ولا تمنح موافقة سريرية أو صلاحية لإطلاق نتائج.
