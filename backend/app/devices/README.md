# Device Integration Domain

تجمع هذه الحزمة نماذج وهوية ورسائل جهاز وقياسات محجورة وتدفقات outbox الخاصة بالتكامل مع أجهزة المختبر أو محطات العمل. لا يعني وجود هذه الحزمة أن الجهاز يستطيع إنشاء `LabResult` أو اعتماد نتيجة أو إطلاقها.

## المكوّنات

| المكوّن | المسؤولية |
|---|---|
| `models.py` | هوية الجهاز الموثوق ورسائل inbox والقياسات المحجورة والنماذج المساندة. |
| `routes.py` | أوامر إدارة/مراجعة مقيدة بالتفويض وfeature flags والحارس السريري. |
| `service.py` | انتقالات ضيقة للقياس، تشمل الحجر والمراجعة أو الرفض. |
| `schemas.py` | عقود الإدخال والإخراج المقيدة. |
| `outbox.py` | تسليم غير متزامن مع نطاق المؤسسة وعدم التكرار. |

## قواعد السلامة

تظل مسارات الجهاز **default-deny**. لا تقبل رسالة جهاز كنتيجة سريرية، ولا تنشئ نتيجة أو تغير عينة/طلباً أو تطلق نتيجة من هذه الحزمة. أي مسار قبول بشري مستقبلي يحتاج هوية عينة متحققة، صلاحية دور، `If-Match`، مفتاح عدم تكرار، حارس أمر، تدقيق، وآلة حالات مفصّلة.

لا تضع أسرار أو شهادات أو payloadات تحتوي PHI في الكود أو الأمثلة أو السجلات. لا يشغّل API process sockets أجهزة حية؛ نشر بوابة محلية وmTLS وPKI وUAT تشغيلية مستقلة مطلوبة قبل أي pilot حي.

## الاختبار

عدّل الحزمة فقط مع اختبارات الحجر والعزل وعدم التكرار وحالات الرفض. اختبر bridge منفصلاً باستخدام بيانات تركيبية؛ لا تصل جهازاً أو مختبراً حياً من بيئة التطوير.
