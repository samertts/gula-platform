# Security — Auth, Authorization & Encryption

This module implements the GULA Platform security layer: JWT handling (`auth.py`), RBAC with 9 roles and 13 permissions (`rbac.py`), ABAC (`abac.py`), encryption (`encryption.py`), rate limiting (`rate_limit.py`), MFA (`mfa_service.py`), OAuth2 provider (`oauth2_provider.py`), SAML (`saml_service.py`), session management (`session.py`), service accounts (`service_accounts.py`), intrusion detection (`intrusion_detection.py`), Redis client (`redis_client.py`), and request dependency injection (`dependencies.py`, `consent_dep.py`).
