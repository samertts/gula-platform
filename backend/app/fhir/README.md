# FHIR Interoperability

تعرض هذه الحزمة واجهات ومحوّلات FHIR R4 داخل المنصة. إصدار معيار FHIR (`4.0.1`) مستقل عن نسخة تطبيق GULA؛ لا تغيره ترقية نسخة المنصة أو metadata التشغيلية.

## المسؤوليات

| المكوّن | الدور |
|---|---|
| `__init__.py` | تصدير أنواع ومحوّلات FHIR العامة المدعومة. |
| `_capabilities.py` | بيان قدرات FHIR المعلن وموارده وإصدار برنامج المنصة. |
| `_reference.py` | إنشاء مراجع FHIR المقيدة. |
| `terminology.py` | خدمات المصطلحات والتحقق المرجعي. |
| `_scorecard.py` و`_validation_report.py` | قياس وتقرير التوافق؛ لا يمثلان اعتماداً سريرياً. |

## قيود التبادل

كل قراءة أو تحويل FHIR يبقى مقيداً بالمصادقة والتفويض وعزل المؤسسة. لا يحول mapper أو CapabilityStatement سجلًا سريرياً إلى مورد قابل للعرض تلقائياً، ولا يسمح للوصول إلى مورد من مؤسسة أخرى. يجب منع PHI من السجل والتقرير والمثال، واستعمال بيانات تركيبية في الاختبارات.

الكتابة أو قبول نتائج المختبر أو إطلاقها لا يكتمل عبر طبقة FHIR وحدها؛ تتبع العمليات الحرجة حارس الأمر السريري، والتحكم في النسخة، وعدم التكرار، والتدقيق، وآلة الحالات المعتمدة.

## الاختبار

بعد تعديل العقود أو الموارد أو البيان، شغّل اختبارات FHIR الشاملة والتوافق والتقسية وR4 exchange من `backend/`. لا تعدل claims القدرات لتعلن مورداً أو عملية غير مدعومة فعلياً.
