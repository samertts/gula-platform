# Clinical Gateway

هذه الحزمة هي بوابة تنسيق للوصول السريري المحدود والعقود المرتبطة به. يصف `__init__.py` نطاقها بأنه **canonical, read-only**؛ لا ينبغي اعتبارها طريقاً لكتابة موارد سريرية أو تجاوز التدقيق أو العزل المؤسسي.

## المكوّنات

| المكوّن | الدور |
|---|---|
| `routes.py` | تعريف واجهات البوابة والتحقق من سياق الطلب. |
| `service.py` و`session_facade.py` | تنسيق الخدمات وجلسة العرض من دون منح صلاحيات جديدة. |
| `context.py` و`contracts.py` | حدود بيانات وسياقات قراءة صريحة. |
| `rollout.py` | ضوابط تمكين مرحلية يجب أن تبقى default-deny عند غياب اعتماد. |

## قواعد السلامة

لا تضف endpoint كتابة سريرية إلى هذه الحزمة إلا بعد تصميم منفصل يطبق التفويض والعزل و`If-Match` وعدم التكرار وحارس الأمر وسجل التدقيق. لا تعِد كائنات تحتوي PHI في سجلات الأخطاء، ولا تتجاوز عزل المؤسسة بسبب واجهة facade.

## الاختبار

عند تعديل أي route أو عقد، شغّل اختبارات البوابة والعزل والتفويض والانحدار الخلفي من `backend/`. يجب أن تثبت الاختبارات أن قراءة مؤسسة لا تكشف وجود مورد مؤسسة أخرى.
