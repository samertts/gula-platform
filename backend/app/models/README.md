# Models — SQLAlchemy ORM Layer

This module contains all SQLAlchemy ORM model classes representing the GULA Platform database schema. 17 models covering: `Patient`, `Lab`, `LabUser`, `LabOrder`, `LabResult`, `Sample`, `TestType`, `TestResult`, `AuditLog`, `Outbox`, `Consent`, `Claim`, `Edge`, `MfaDevice`, `OAuth2Client`, `OAuth2Token`, `Organization`, `Subscription`, `ServiceAccount`, `User`, `AiInteraction`, `CanonicalPatient`, `QualityControl`.
