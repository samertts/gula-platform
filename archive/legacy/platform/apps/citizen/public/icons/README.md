# App Icons

Place the following icon files in this directory:

- icon-48x48.png
- icon-72x72.png  
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

Generate using:
```bash
npx pwa-asset-generator path/to/logo.svg ./public/icons
```

Or use the platform's design system logo.
