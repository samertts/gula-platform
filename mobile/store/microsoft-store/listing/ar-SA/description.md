# منصة GULA - نظام إدارة معلومات المختبرات لنظام Windows

## إدارة مختبر كاملة لسطح المكتب

توفر منصة GULA لنظام Windows القوة الكاملة لنظام إدارة معلومات المختبرات (LIMS) السحابي كتطبيق سطح مكتب أصلي. صُممت للمختبرات الطبية في العراق والشرق الأوسط، وتقدم GULA إدارة مختبر على مستوى المؤسسات بواجهة عربية أولاً.

## الميزات الرئيسية

### إدارة المرضى
- سجل شامل للمرضى مع مؤشر المرضى الرئيسي
- دعم الهوية الوطنية العراقية ومعرف الصحة SNDHS
- بطاقات مرضى رقمية قائمة على QR مع التاريخ السريري
- تخزين مشفر لجميع المعلومات الشخصية القابلة للتحديد

### إدارة الطلبات
- إنشاء وتتبع طلبات المختبر مع تحديثات في الوقت الفعلي
- دعم الطلبات الروتينية والعاجلة (STAT) والطلبات الدائمة
- لوحات وملفات اختبار قابلة للتكوين
- إنشاء الباركود ورموز QR لوسم العينات

### لوحة النتائج
- إدخال النتائج والتحقق منها في الوقت الفعلي
- وضع علامات تلقائية على القيم الحرجة والتنبيه
- التحقق من النطاق المرجعي مع نطاقات محددة بالعمر والجنس
- كشف تغييرات الدلتا
- تقارير نتائج PDF قابلة للطباعة

### تكامل الأجهزة
- اتصال مباشر ASTM/HL7 مع المحللات الرئيسية
- دعم أجهزة Sysmex و Roche و Mindray و Abbott و Siemens
- اتصال ثنائي الاتجاه لطلب الاختبارات واسترجاعها

### القدرة على العمل دون اتصال
- وظائف كاملة دون اتصال بالإنترنت
- مزامنة تلقائية عند استعادة الاتصال
- حل ذكي للنزاعات

### ميزات سطح المكتب الخاصة
- عمل متعدد النوافذ للمهام المتزامنة
- اختصارات لوحة المفاتيح للتشغيل الفعال
- دعم شاشات عالية الدقة
- تكامل أصلي مع Windows 10/11
- تغليف MSIX للنشر المؤسسي
- دعم سياسات المجموعة للبيئات المدارة

## المتطلبات

- Windows 10 الإصدار 1809 أو أحدث / Windows 11
- 4GB RAM (8GB موصى به)
- 500MB مساحة تخزين متوفرة
- اتصال بالإنترنت للإعداد الأولي والمزامنة
