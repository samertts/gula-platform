# GULA Platform - Laboratory Information Management System for Windows

## Complete Laboratory Management for Your Desktop

GULA Platform for Windows provides the full power of our cloud-based Laboratory Information Management System (LIMS) as a native desktop application. Designed for medical laboratories in Iraq and the Middle East, GULA delivers enterprise-grade laboratory management with an Arabic-first interface.

## Key Features

### Patient Management
- Comprehensive patient registry with Master Patient Index
- Support for Iraqi National ID, SNDHS Health ID
- QR-based digital patient cards with clinical history
- Encrypted storage of all personally identifiable information

### Order Management
- Create and track laboratory orders with real-time updates
- Support for routine, urgent (STAT), and standing orders
- Configurable test panels and profiles
- Barcode and QR code generation for specimen labelling

### Results Dashboard
- Real-time result entry and validation
- Automatic critical value flagging and alerting
- Reference range validation with age/gender-specific ranges
- Delta change detection
- PDF and printable result reports

### Instrument Integration
- Direct ASTM/HL7 connectivity with major analysers
- Support for Sysmex, Roche, Mindray, Abbott, Siemens
- Bidirectional communication for test ordering and retrieval

### Offline Capability
- Full functionality without internet connection
- Automatic synchronisation when connectivity restored
- Intelligent conflict resolution

### Desktop-Specific Features
- Multi-window workflow for simultaneous tasks
- Keyboard shortcuts for efficient operation
- High-DPI display support
- Windows 10/11 native integration
- MSIX packaging for enterprise deployment
- Group Policy support for managed environments
- Integration with Windows authentication

## Security

- End-to-end encryption (TLS 1.3 / AES-256)
- Windows Hello biometric authentication
- Role-based access control
- Complete audit logging
- HIPAA-compliant

## Languages

- English (full interface)
- Arabic (full interface with RTL layout)

## System Requirements

- Windows 10 version 1809 or later / Windows 11
- 4GB RAM (8GB recommended)
- 500MB available storage
- Internet connection for initial setup and sync

GULA Platform for Windows is available to authorised laboratory professionals through organisational subscriptions.
