## Additional Information

### Target Age Group
- Healthcare professionals, laboratory staff, and authorised medical personnel
- Minimum age: 18+

### App Function
The GULA Platform app is a professional Laboratory Information Management System (LIMS) designed exclusively for use by authorised medical laboratory staff. It provides tools for patient management, order tracking, and result reporting in a clinical laboratory setting.

### Data Handling
- No advertising ID collected
- No location data collected
- No social features
- No user-generated content shared
- All patient data encrypted in transit and at rest
- Biometric data stored only on-device

### Compliance
- HIPAA-compliant
- Designed to meet Iraqi Ministry of Health data standards
- All data processing is for legitimate medical purposes only
