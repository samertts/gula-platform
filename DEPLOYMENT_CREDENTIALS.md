## 7. Deployment Process

### Step 1: Prepare Repository

```bash
cd /home/ubuntu/gula-platform

# Ensure all files are committed
git add -A
git commit -m "feat: production deployment"
git push origin main
```

### Step 2: Create Render Account

```
1. Go to https://render.com
2. Sign up with GitHub
3. Authorize GitHub access
```

### Step 3: Create Web Service

```
1. Click "New +" → "Web Service"
2. Select: samertts/gula-platform
3. Configure as per section 1.2
4. Click "Create Web Service"
```

### Step 4: Configure Environment Variables

```
1. Go to Service Settings
2. Add all environment variables from section 1.3
3. Generate secure values for JWT_SECRET and ENCRYPTION_KEY
4. Save
```

### Step 5: Setup Database

```
1. Create MySQL database
2. Get connection string
3. Add to environment variables
4. Run migrations
```

### Step 6: Setup Redis

```
1. Create Redis instance
2. Get connection string
3. Add to environment variables
```

### Step 7: Deploy

```
1. Render will auto-deploy on git push
2. Monitor deployment in dashboard
3. Check logs for errors
```

### Step 8: Configure Domain

```
1. Add custom domain in Render
2. Update DNS records
3. Wait for DNS propagation (5-30 minutes)
4. Verify SSL certificate
```

## 13. Troubleshooting

### Deployment Failed

```
1. Check build logs in Render dashboard
2. Verify environment variables
3. Check database connection
4. Review application logs
```

### Database Connection Error

```
1. Verify DATABASE_URL format
2. Check database credentials
3. Ensure database is running
4. Check firewall rules
```

### Domain Not Working

```
1. Verify DNS records
2. Wait for DNS propagation
3. Check SSL certificate
4. Verify custom domain settings in Render
```
