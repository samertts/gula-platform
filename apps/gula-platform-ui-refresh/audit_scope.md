# نطاق تدقيق GULA المرتبط بالمستخدم

## قواعد التنفيذ غير القابلة للتفاوض

تُعامل الخلفية وقاعدة البيانات وعقود الواجهة بوصفها مصادر الحقيقة. لا تُعرض في الواجهة أي قدرة لا يدعمها عقد خلفي حقيقي، ولا تُنشأ أزرار أو مسارات أو لوحات أو بيانات تشغيلية توحي بوظيفة غير متاحة. لا يُعتمد إخفاء عناصر الواجهة كآلية أمان؛ تبقى المصادقة والتفويض في الخلفية، وتُترجم الواجهة قراراتهما إلى حالات واضحة للمستخدم.

## محاور التدقيق

| المحور | ما يجب التحقق منه |
|---|---|
| الهوية والثقة | الحساب، وسائل الدخول، التحقق، الجلسات، الاستعادة، مستويات الثقة، وسجل التدقيق |
| المؤسسات ومساحات العمل | المؤسسة، العضويات، مساحات العمل، الأدوار، الصلاحيات، الاستحقاقات، وتبديل السياق |
| العقد والواجهة | كل مسار وصفحة وحوار وحالة تحميل أو خطأ أو منع صلاحية وربطها بالعقد والخدمة الواقعية |
| البيانات الصحية | الخصوصية، سبب الوصول، الموافقة، الوصول الطارئ، التسلسل التدقيقي، وإظهار المعلومات حسب الحاجة |
| التشغيل غير المتصل | حالة الاتصال، طابور المزامنة، التعارضات، إعادة المحاولة، وعدم ادعاء مزامنة لم تنجح |
| التعدد اللغوي | العربية العراقية والعربية الرسمية، دعم RTL/LTR المختلط، عزل النصوص ثنائية الاتجاه، وعدم ترجمة البيانات السريرية تلقائيًا |

## قواعد واجهة المستخدم

تتجه الواجهة إلى مساحة عمل تكيفية واعية بالسياق بدلاً من لوحة ثابتة. تعرض السياق النشط للمؤسسة ومساحة العمل والدور وحالة الاتصال، وتظهر الأوامر والإجراءات والنتائج بحسب الصلاحية الفعلية فقط. تُعطى الأولوية للوضوح السريري والهدوء والسرعة على المؤثرات البصرية، مع حالات صريحة للتحميل والفراغ والخطأ وعدم الصلاحية وعدم الاتصال والمزامنة.

## مخرجات التدقيق المطلوبة

ينتج التدقيق جردًا لبنية الخلفية وعقودها، وكتالوجًا لمسارات الواجهة والصفحات والنوافذ وحالاتها، ومصفوفة تربط المجال والمسار والواجهة والعقد ومساحة العمل والأدوار والصلاحيات والمنصات وحالة التنفيذ. لا يُصنّف أي عنصر بوصفه مكتملًا دون دليل قابل للتحقق من العقد والتكامل والاختبار.
