# جرد سطح الواجهة — GULA

## منهجية التصنيف

يجمع هذا السجل بين مسارات `frontend-v3/src/routes/index.tsx`، ومكوّنات الحماية والتنقل، وارتباطات الصفحات الفعلية بطبقة `api/endpoints.ts`. لا يعني وجود مسار أو عنصر قائمة أن عملية الخلفية متاحة؛ يصنّف السطح بأنه **مربوط** فقط عند وجود استدعاء متحقق، وبأنه **قالب أو إيحاء** عندما يعرض عناصر تحكم أو ادعاءات دون عقد تشغيل مستخدم فعليًا.

## طبقات الدخول والحماية

| الطبقة | التنفيذ القائم | الملاحظة |
|---|---|---|
| المصادقة | `ProtectedRoute` يعيد غير المسجل إلى `/login` | حماية دخول عامة موجودة. |
| حراسة الأدوار | `RoleGuard` يعتمد قائمة أدوار محلية لكل مسار | حماية مرئية مفيدة، لكنها لا تستبدل تفويض الخادم ولا تفحص permission محددة. |
| التنقل | `NAV_ITEMS` يرشّح عناصره بمصفوفة `ROLE_PERMISSIONS` محلية | يشير إلى صلاحيات على مستوى الشاشة، لكن المصفوفة تحتاج مصالحة مع عقود الخادم. |
| بيئة العرض | `DashboardLayout` يعلن وضع المعاينة ويشير إلى بيانات اصطناعية | الإفصاح ظاهر، وينبغي الإبقاء عليه دائمًا عند عدم وجود عقد عمليات فعلي. |

## الأسطح التشغيلية الأساسية

| المسار | العقدة أو الاستدعاء المرصود | الحماية المرئية | الحالة الحالية | فجوة الواجهة المهمة |
|---|---|---|---|---|
| `/dashboard` | `dashboardApi.dashboard` أو مسار معاينة | مستخدم مسجل | مربوط | يتطلب تمييز البيانات التجريبية عن التشغيلية في المصدر لا في النص فقط. |
| `/patients` | `patientsApi.list` | `staffRoles` | مربوط بالقراءة | يلزم التحقق من الفلاتر والتفاصيل والعمليات قبل إظهارها كمتاحة. |
| `/orders` | `ordersApi.list({search, limit})` | `staffRoles` | مربوط بالقراءة والبحث | يعرض حالة الخلفية الخام بدل تسمية مستخدم مترجمة، ولا يعرّف حالة خطأ صريحة أو تفويض الإجراء. |
| `/results` | `resultsApi.list` | `staffRoles` | مربوط بالقراءة | يلزم جرد إجراءات الإدخال والاعتماد والتحرير قبل إظهارها. |
| `/samples` | `samplesApi.list` | `labRoles` | مربوط بالقراءة | يحتاج إثباتًا لعقود السلسلة الحيازية أو الحالات قبل توسيع العمليات. |
| `/alerts` | `criticalAlertsApi.list` | `readonlyRoles` | مربوط بالقراءة | يحتوي معالجة تحميل وفراغ وخطأ، ويحتاج فحص التصفية والإقرار فقط إن وجدت العقود. |
| `/admin/audit` | `adminApi.auditLogs({limit:50})` | `adminRoles` | مربوط بالقراءة | جدول محدود بلا غرض وصول أو مصدر دليل أو تفاصيل حدث قابلة للتدقيق. |
| `/compliance` | `complianceApi.systemStatus` فقط | `adminRoles` | ربط جزئي | أزرار تقارير التدقيق والأمان وFHIR بلا معالجات؛ لا يجوز إيهام المستخدم بإتاحة التصدير. |
| `/security` | `securityApi.status` غير معروض في البطاقات | `adminRoles` | قالب بربط غير مستثمر | عمليات كلمة المرور وMFA والجلسات والسجل ليست مرتبطة بعقود ظاهرة. |
| `/identity` | لا استدعاء API | `staffRoles` | قالب | لا تعرض مصدر هوية أو حالة تحقق أو دليل أو قيود وصول. |
| `/capabilities/healthcare-consent` | طلب خام إلى `/healthcare-consent` | `readonlyRoles` | ربط غير متوافق | لا يستخدم `grant/revoke/check` المؤكدة ولا يعرض نطاقًا أو متلقيًا أو انتهاءً أو سجلًا. |

## أسطح ذات حساسية عالية

| المجال | السطح الحالي | الحكم | إجراء التصميم المسموح |
|---|---|---|---|
| الهوية والتحقق | صفحة هوية فارغة، ومسارات خلفية بحدود تحقق صريحة | لا توجد تجربة تحقق موثوقة بعد | عرض حالة محايدة أو منع الوصول؛ لا تدّع OCR/NFC/تحققًا وطنيًا. |
| الموافقة والخصوصية | صفحة موافقات عامة بلا إدارة فعلية | لا يوجد مركز خصوصية أو تصحيح أو تصدير شخصي | لا يُبنى إلا بعد عقد scope/grantee/expiry/audit محدد. |
| سجل الوصول | جدول إداري محدود وملخص امتثال للمختبر | ليس كشف وصول للمستخدم | يظل إداريًا ومحدودًا حتى توافر عقد موضوعي وقواعد إتاحة. |
| الامتثال والتصدير | مؤشرات وأزرار لا تغطي العقود المتاحة كلها | خطر إيحاء بقدرة غير موجودة | تعطيل الإجراء بوضوح أو ربطه بعقد مؤكد مع رسالة خطأ. |

## فجوات بنيوية مؤكدة

| المعرف | الفجوة | الأثر | الأولوية |
|---|---|---|---|
| UI-01 | القوائم تستخدم مصفوفة صلاحيات محلية؛ `RoleGuard` يعمل بقوائم أدوار منفصلة. | عدم اتساق محتمل بين العنصر المرئي والمسار أو الخادم. | مرتفعة |
| UI-02 | عدة أيقونات واردة في `NAV_ITEMS` غير معرّفة في `iconMap`. | ظهور أيقونة بديلة يضعف قابلية التعرف، خصوصًا في واجهات الهوية والقدرات. | متوسطة |
| UI-03 | صفحات الهوية والأمان والامتثال تستخدم قوالب أو عناصر تحكم لا تقابلها عمليات مؤكدة. | خطر ثقة خاطئة، وبالأخص في نطاق صحي حساس. | حرجة |
| UI-04 | صفحة الطلبات تسرب قيم حالات الخدمة الخام في شارة عربية. | عدم اتساق اللغة وعدم وضوح تشغيلي. | متوسطة |
| UI-05 | لا يوجد نمط موحد ظاهر لتقييد الإجراءات حسب حالة التحميل أو الخطأ أو المنع. | سلوك غير متوقع في الصفحات المكثفة. | مرتفعة |

## قرار التنفيذ التالي

يتقدم العمل فقط بتصحيح الفجوات التي يمكن دعمها من العقود الحالية، مثل توحيد عرض حالة الطلبات، وإخفاء أو تعطيل الإجراءات غير الموصولة بوضوح، وربط عرض الامتثال والتدقيق بالعقود المقروءة بالفعل. أما مراكز الخصوصية أو التحقق الرسمي أو الإجراءات عالية الأثر فتظل ضمن توصيات عقدية وليست ميزات واجهة في هذه النسخة.
