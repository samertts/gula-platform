## User Type Lifecycle

Each user type follows a configurable provisioning workflow:

```
Onboarding → Credentialing → Training → Activation → Periodic Review → Offboarding
```

- **Onboarding**: Identity verification, document collection
- **Credentialing**: License/degree verification for clinical types
- **Training**: Platform orientation, role-specific training
- **Activation**: Account enablement, permission assignment
- **Periodic Review**: Annual access review, license renewal check
- **Offboarding**: Account suspension, data retention, audit trail
