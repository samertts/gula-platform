# GLOSI Decision Records

هذا المجلد مخصص للقرارات الصادرة بعد مراجعة بشرية (APPROVED / REJECTED / DEFERRED)، ويحتوي أيضاً على ملفات تتبع للقرارات **المقترحة غير الملزمة** (`PROPOSED`) للدفعة البحثية الأولى.

ملفات `PROPOSED` ليست اعتماداً رسمياً ولا تسمح بأي دمج أو تغيير في GULA. لا يصبح أي قرار رسمياً قبل اكتمال المراجعة الفنية والأمنية والقانونية وإصدار ADR داخل GULA.

## قواعد

1. اسم الملف: `GLOSI-DEC-NNNN-<slug>.md` (مثل `GLOSI-DEC-0001-openelis-global.md`).
2. كل قرار رسمي يشير إلى `registry_id` و`decision_id`.
3. لا يُحذف قرار؛ يُستبدل بحالة `SUPERSEDED` مع مرجع البديل.
4. كل قرار يتضمن المراجعين البشريين وتواريخ المراجعة والأدلة وخطة الرجوع.
5. لا يُنشئ وكيل AI قرار اعتماد رسمياً.

## القالب

استخدم `TEMPLATE.md` عند إصدار قرار رسمي.

## الحالة الحالية

- 16 ملف قرار `PROPOSED` غير ملزم، مولّد من السجل عبر `tools/build_decision_records.py`.
- لا توجد قرارات رسمية (`APPROVED` / `REJECTED` / `DEFERRED`).
