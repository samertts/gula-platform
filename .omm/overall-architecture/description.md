National health platform for the Iraqi Ministry of Health. Clean Architecture monorepo: React/Arabic-first frontend (frontend-v3, mobile, hospital_desktop), FastAPI backend (backend/app) with 11 canonical Domains + Domain Sovereignty framework (backend/app/domain_platform), a 50-service Shared Core (shared/), and infrastructure for PostgreSQL 16, Redis 7, MinIO/S3 and Redis-Streams event bus. Offline-first, FHIR R4, HL7, ISO 15189, multi-tenant, RBAC/ABAC, immutable audit.
