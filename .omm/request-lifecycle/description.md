End-to-end path of a platform request: client → nginx → FastAPI middleware stack (request ID, CORS allowlist, rate limiting, OTLP tracing, JSON logging) → auth dependency (get_current_user, token blacklist, permission-version check) → RBAC enforcement via require_permission using shared/rbac role→permission maps → route → domain service → PostgreSQL/Redis → structured error or JSON response; every mutating action is appended to the immutable audit hash-chain.
